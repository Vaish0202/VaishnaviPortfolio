    Projects

    01
    Personal project · Research

    QA Assistant

    An agentic system that decides whether a failing test is an application bug or a problem in the test code, then drafts the Jira ticket or the fix.

    • XGBoost on 52 engineered features makes the call in under a millisecond; Llama 3.2 writes the explanation and fix suggestions.
    • Five LangGraph agents, with a human approval step before any Jira ticket is created.
    • 76.7% accuracy on a 30-case evaluation, up from a 60% LLM-only baseline. Published as a preprint.

    LangGraph · XGBoost · Llama 3.2 · Ollama · FastAPI · React · Jira API

    GitHub ↗Paper ↗
    02
    Endava · Proof of concept

    AI-Powered Test Automation Platform

    Takes a Jira story to reviewed Playwright BDD automation, with a person approving at the key steps.

    • LangGraph workflow: requirement check, browser discovery, test design, generation, validation, healing and execution.
    • RAG over pgvector supplies the team's testing standards, and the LLM returns structured, schema-checked output.
    • PostgreSQL stores every run, so a workflow can pause for approval and resume where it stopped.

    LangGraph · OpenAI · FastAPI · React · PostgreSQL · pgvector · MCP · Playwright

    03
    Endava · Proof of concept

    Test Framework Migration Platform

    Converts Selenium/Cucumber and Cypress suites into Playwright frameworks that actually run.

    • Parses a repository into an intermediate representation and dependency graph; a deterministic planner orders the work.
    • Generation mixes deterministic transforms with LLM calls, checked by static validation and sandboxed test runs.
    • Failures are classified and repaired, and any repair that causes regressions is rolled back.

    LangGraph · OpenAI · FastAPI · Tree-sitter · ChromaDB · Redis · Docker
